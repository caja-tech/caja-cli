# Specification Site

This site contains the project's specifications, built with [Astro](https://astro.build) (using the default theme due to network constraints with Starlight).

## Setup and Run

To run this site on your local machine, you need to have [bun](https://bun.sh/) installed.

1. Navigate to the `spec` directory:
   ```bash
   cd spec
   ```
2. Install dependencies (requires a stable network connection):
   ```bash
   bun install
   ```
3. Start the development server:
   ```bash
   bun run dev
   ```
4. Open the site in your browser (usually http://localhost:4321).
